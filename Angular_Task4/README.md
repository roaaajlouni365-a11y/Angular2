# ElectroShop Task 4

Dynamic product cards using Angular control flow and directives.

## Run the project

```bash
npm install
npm start
```

Open `http://localhost:4200/` in your browser.

The product list demonstrates `@for`, `@if`, `@switch`, `ngClass`, and `ngStyle` with eight products. Change `selectedCategory` and `orderStatus` in `src/app/product-list/product-list.ts` to view the other messages.
